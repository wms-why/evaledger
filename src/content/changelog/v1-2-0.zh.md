### 新增

- **DeepSeek 定价页** — 新路由 `/deepseek-api-pricing`(中英双语),含 V4-Pro 与 V4.1-Flash 每 token 单价、非高峰时段、prompt cache 价格、8 条 FAQ。独立的长尾 URL、自有 title / description / JSON-LD;通过 `RelatedCalculators` 从所有计算器页互相链入。
- **DeepSeek 定价卡片** — 新组件 `DeepSeekSection` 直接从 `REGISTRY` 读 V4-Pro / V4.1-Flash 的 `cachedInputPricePer1M`,cache hit 折扣百分比与源头数据永远不会漂移。

### 修复

- **DeepSeek off-peak 文案** — 首页与 `/token-cost-calculator` 之前写的是"10 倍便宜" + 错误时段(16:30–00:30 UTC)。改为官方口径的 `~50%` —— 周一至周五(不含中国法定假日)、高峰 UTC 01:00–04:00 与 06:00–10:00、其余时段为非高峰。`model-prices.ts` 顶部留了 `// TODO` 提醒去 `platform.deepseek.com` 复核。
- **首页与 `/token-cost-calculator` 自相残杀** — title 与 description 完全相同(79 字符)。首页改成品牌门户语气(`TokenCalculator — Free LLM Token Cost Calculator`,48 字符),计算器页用独立 title(`Token Cost Calculator — Compare Every LLM`,41 字符),两条 meta description 也分开。
- **robots.txt 把 agent 用的价格源屏蔽了** — `/api/prices.json` 现在显式 `Allow`,GPTBot / ClaudeBot / PerplexityBot 可以抓到;`/api/` 下其它写入端点仍 `Disallow`。
- **`RelatedCalculators`、`PricingTLDR`、`Tips` 加可选 `itemsKey` prop** — 页面专属 bullet(DeepSeek TLDR 与 tips)不再污染跨厂商页面。
