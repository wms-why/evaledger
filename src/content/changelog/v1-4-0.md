### Added

- **Kimi K3.1 Pro** — a new release post (en + zh) for Moonshot's 2026-10-24 launch: $2 input / $10 output per 1M tokens with a $0.20 cache read and a 1,048,576-token window, a Highspeed twin at $4 / $20, open weights promised by 2026-11-04, and Terminal-Bench 4.0 at 65.7 against Opus 5.5's 66.4. Registry and leaderboard rows follow the release article in the same commit; it stays unranked until the boards can measure it on the core benchmarks rather than a vendor-only table.
- **DeepInfer** — a new release post (en + zh) for DeepSeek's 2026-10-20 publication of the inference framework behind V4.1-Flash under Apache-2.0: one model, NVIDIA SM100 / Huawei Ascend 950 only, and an explicit boundary (no KV-cache cluster, no prefill/decode disaggregation, no load balancing). A serving release, not a model release — no price or score moved.

### Changed

- **Homepage Popular comparisons now leads with the new frontier** — the list reads `claude-opus-5.5` vs `gpt-6-astra`, `claude-opus-5.5` vs `claude-opus-5`, `gemini-4-argon` vs `gemini-3.1-pro` and `deepseek-v4.1-flash-1017` vs `deepseek-v4.1-flash` before the older pairs, so the page answers "is the new checkpoint worth switching to?" instead of only listing last quarter's flagships. The `/compare` CTA anchor text is now **Compare LLM benchmarks & prices →**.

### Fixed

- **Claude subscription-vs-API break-even card** — `ClaudeSubscriptionSection` no longer computes from a hardcoded Sonnet 4.5 rate; it calls the shared `claudeBreakEven()` / `formatBreakEvenM()` helper against Sonnet 5, so the Pro and Max cards print the same numbers as the FAQ on the same page (~2.86M input + 1.43M output for Pro, ~28.6M input + 14.3M output for Max). The card and the FAQ used to disagree by 1.5×.
- **DeepSeek cache-price copy** — the DeepSeek TLDR and Tips bullets claimed an unqualified $0.003/M — 99% off, contradicting the live prompt-cache pricing box ($0.006/M at peak, 98% off). Both bullets now state the peak and off-peak tiers separately, matching the registry timeline.

### Unchanged

- **URLs and prices.** Route slugs, the canonical domain and `/api/prices.json` are untouched. Kimi K3.1 Pro's price is a new row, not an edit to an existing one.
