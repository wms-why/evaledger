### 新增

- **Kimi K3.1 Pro** — Moonshot 2026-10-24 发布的新评测文章(中英双语):每 1M token 输入 $2 / 输出 $10,缓存读 $0.20,1,048,576 token 窗口,另有 Highspeed 版本 $4 / $20,权重承诺 2026-11-04 前开源,Terminal-Bench 4.0 65.7 对比 Opus 5.5 的 66.4。价格表与排行榜行与文章在同一次提交里落地;在站内榜单能用核心 benchmark 而非厂商自测表复测之前,它只列出、不排名。
- **DeepInfer** — DeepSeek 于 2026-10-20 把 V4.1-Flash 背后的推理引擎以 Apache-2.0 开源,新增评测文章(中英双语):只支持单个模型,硬件限定 NVIDIA SM100 与华为昇腾 950,并明确边界(不含 KV-cache 集群、prefill/decode 分离与副本负载均衡)。这是一次服务栈发布,不是模型发布,价格与分数均未变动。

### 变更

- **首页 Popular comparisons 改为新旗舰打头** — 列表现在以 `claude-opus-5.5` vs `gpt-6-astra`、`claude-opus-5.5` vs `claude-opus-5`、`gemini-4-argon` vs `gemini-3.1-pro`、`deepseek-v4.1-flash-1017` vs `deepseek-v4.1-flash` 开头,再接旧的组合,让首页回答"新 checkpoint 值不值得换",而不是只列上季度的旗舰。`/compare` 的按钮锚文本改为 **对比大模型 benchmark 与价格 →**。

### 修复

- **Claude 订阅 vs API 盈亏平衡卡片** — `ClaudeSubscriptionSection` 不再硬编码 Sonnet 4.5 的费率,改为调用共享的 `claudeBreakEven()` / `formatBreakEvenM()`,以 Sonnet 5 计算;Pro 与 Max 卡片因此和同页 FAQ 打印同一组数字(Pro 约 2.86M 输入 + 1.43M 输出,Max 约 28.6M 输入 + 14.3M 输出)。此前卡片与 FAQ 差了 1.5 倍。
- **DeepSeek 缓存价格文案** — DeepSeek TLDR 与 Tips 两条都写成不带限定的 $0.003/M、便宜 99%,和同屏实时计算的 prompt-cache 价格框($0.006/M 高峰、98% off)冲突。两条现在分别写明高峰与错峰两个档位,与注册表的时间线一致。

### 未改动

- **URL 与价格。** 路由 slug、规范域名与 `/api/prices.json` 均未变动。Kimi K3.1 Pro 是新增价格行,不是修改既有价格。
