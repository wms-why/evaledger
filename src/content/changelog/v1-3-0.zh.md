### 变更

- **新域名 —— [evaledger.com](https://evaledger.com)** 已成为计算器的正式站点。所有 canonical URL、`hreflang` 多语言备选、`og:url`、sitemap、`robots.txt` 与 RSS feed 现在都指向 `evaledger.com`；旧域名暂时仍提供同样的服务，但每个页面的 canonical 链接都已指向新域名。
- **新名字 —— EvalLedger。** 站标、页面标题、页脚、邮件模板与法务页现在都写作 EvalLedger。产品本身没有变化：同一套实时分词器、同一张覆盖 OpenAI / Claude / Gemini / DeepSeek / Grok 的单 token 价格表、同一套 OpenRouter 加价系数与 Claude 订阅 vs API 盈亏平衡计算。
- **联系邮箱 —— `hello@evaledger.com`** 取代了页脚、服务条款与隐私政策里的旧邮箱。

### 不变

- **URL 不变。** 路由路径（`/token-cost-calculator`、`/openrouter-pricing-calculator`、`/claude-token-cost-calculator`、`/leaderboard`、`/releases`、`/series`）全部保留——你分享过的链接依然有效。
- **价格数据接口不变。** `/api/prices.json` 仍是机器可读的唯一事实来源。
- **账号不变。** 登录、订阅与赞助记录原样保留，只是换了所在的域名。
