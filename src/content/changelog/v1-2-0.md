### Added

- **DeepSeek pricing page** — new `/deepseek-api-pricing` route (en + zh) with V4-Pro and V4.1-Flash per-token rates, the off-peak schedule, prompt-cache pricing, and 8 FAQ entries. Dedicated `/deepseek-api-pricing` long-tail URL with its own title, description, and JSON-LD; linked from every calculator page via `RelatedCalculators`.
- **DeepSeek pricing section** — `DeepSeekSection` component reads V4-Pro and V4.1-Flash `cachedInputPricePer1M` directly from `REGISTRY`, so cache-hit percentages can never drift from the source data.

### Fixed

- **DeepSeek off-peak copy** — homepage and `/token-cost-calculator` were showing "10× cheaper" with the wrong window (16:30–00:30 UTC). Now `~50% cheaper` against the published schedule (Mon–Fri, excluding Chinese public holidays; peak 01:00–04:00 and 06:00–10:00 UTC; off-peak = all other times). Tagged with a `// TODO` in `model-prices.ts` for re-verification against `platform.deepseek.com`.
- **Homepage vs /token-cost-calculator cannibalization** — title + description were identical (79 chars). Homepage now uses a brand-portal frame (`TokenCalculator — Free LLM Token Cost Calculator`, 48 chars) and the calculator route gets its own (`Token Cost Calculator — Compare Every LLM`, 41 chars), with two distinct meta descriptions.
- **robots.txt blocked the agent-facing price feed** — `/api/prices.json` is now explicitly `Allowed` so GPTBot, ClaudeBot, and PerplexityBot can ingest it; the broader `/api/` write endpoints remain `Disallow`ed.
- **`RelatedCalculators` and `PricingTLDR` / `Tips` now take an optional `itemsKey` prop** — page-specific bullets (DeepSeek TLDR + tips) no longer pollute the cross-provider pages.
