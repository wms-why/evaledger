## 一句话结论

- **Grok 4.7 是每 1M token 输入 $2、输出 $6，上下文 500,000 token。** 输出 $6 比 GPT-5.6 sol 的 $20 便宜 70%——sol 的 $4 / $20 是促销价，到 2026-11-21 为止；2026-11-22 起它是 $30，那时候省的是 80%——比 Claude Opus 5 的 $25 便宜 76%。缓存读 $0.50，是新鲜输入价的 25%，省 75%。
- **长上下文档位是真的，门槛在 200K。** 提示词达到 200,000 token 后，xAI 对整个请求按 $4 输入 / $12 输出计费——两边都翻倍。500,000 的窗口不是全程平价，计算器已经把这个跳档算进去了。
- **窗口几乎翻倍，旧款直接退役。** Grok 4 是 256,000 token，Grok 4.7 是 500,000；同时 Grok 4 已被标成 delisted，备注是「Replaced by Grok 4.7」。这不是二选一，是升级。
- **我们只核验到 2 项跑分，是本系列最薄的一张卡。** Terminal-Bench 4.0 38.0、DeepSWE v1.1 71.0（来源里写作「DeepSWE」），推理、知识、数学一项都没有。

## 发布了什么

- **新一代 Grok，更便宜。** Grok 4.7：输入 $2 / 1M、输出 $6 / 1M，缓存读 $0.50，上下文 500,000 token，active。xAI 的定价表把发布日期标在 2026-09-21。
- **Grok 4 退役但保留。** 原来是 $3 / $15，现在标为 delisted，备注「Replaced by Grok 4.7」；这一行留着，老价格搜索还能落到一个真实的数字。
- **窗口几乎翻倍。** 从 256,000 到 500,000 token。处理长文档时，你大约可以少设计一半的切块逻辑，而单价还更低——前提是提示词没到 200K 的跳档线。
- **缓存价和长上下文档位都在官方表里。** xAI 同时印了短上下文 `$2.00 / $0.50 / $6.00` 和长上下文 `$4.00 / $12.00` 的输入输出对（缓存读也跟着翻倍）。我们之前的页面说两项都没有，那是漏读；现在都已进注册表。

## 成本

- **这个模型真正在拼的是输出。** 每 1M 输出 $6，对 GPT-5.6 sol 的 $20 便宜 70%，对 Claude Opus 5 的 $25 便宜 76%。输入 $2 是 GPT-5.6 sol 的 $4 的一半、比 Claude Opus 5 的 $5 低 60%。这里 sol 的两个数都来自它的促销价，成立到 2026-11-21；2026-11-22 起 sol 是 $5 / $30，同样的比较就变成输出便宜 80%、输入低 60%。
- **和自己上一代比，输出降得更狠。** Grok 4 是 $3 / $15，4.7 是 $2 / $6：输入降 33%，输出降 60%。换代不是一次平价重构。
- **缓存重度负载多拿到一个数，不是零头。** 缓存读 $0.50 = 新鲜输入 $2 的 25%，省 75%。Agent 每轮都重发同一段 system prompt、同一套 tool schema 的场景，省下来的是真金白银。
- **500,000 的窗口不是平价窗口。** 提示词一到 200,000 token，整个请求按 $4 输入 / $12 输出计费，缓存读也跟着翻倍。25 万 token 的请求，实际单价是首页数字的两倍；计算器会算这一跳，报预算时不要只拿 $2 乘 token 数。
- **1:3 的价型要留意。** 输入 $2、输出 $6。内容生成、长文输出、Agent 多轮循环，产生的 token 比读进去的多得多，所以「输出降 60%」才是你真正拿到的那部分便宜。

## 跑分

- **只有 2 项，就是全部。** Terminal-Bench 4.0 38.0、DeepSWE v1.1 71.0——后者在我们引用的来源里写作「DeepSWE」。
- **这两行只能当「相邻」看，不能当排名看。** 同一张表上不同模型覆盖的 benchmark 不一样，共同的地基很窄：一个终端 Agent 列，一个仓库工程列。我们不会把两个分数平均成一个总分。
- **表能告诉你的：** 在这两列上，4.7 和它对比的那几行旗舰处在同一档区间，而价格是零头。这句话只关于这两个 benchmark。
- **表不能告诉你的：** 推理、知识、数学一律没有数据。如果你的产品依赖推理型 benchmark，这张表帮不上忙。

## 该不该换

- **原来就在用 Grok 4：换。** 旧款已经 delisted，新款输入降 33%、输出降 60%，窗口从 256,000 涨到 500,000。继续挂着旧 SKU 没有任何理由。
- **你在用 GPT-5.6 sol 或 Claude Opus 5，而且账单主要来自输出：** $6 的输出价意味着你少付 70%–76%，值得试（其中 sol 那部分是它的促销价，到 2026-11-21；之后 sol 回到 $30，省的是 80%）。挑输出最多的那部分流量先跑（长文生成、Agent 循环、批量任务），用真实数据比质量。
- **输入占大头的场景**（比如长文档 RAG），先看 200K 那条线再报预算：窗口大是理由，但超过 200K 后输入按 $4 计，不是 $2。切块更少仍然有价值，只是省下来的没有首页数字看起来那么多。
- **需要推理或知识能力，就别根据这张表换。** 4.7 在这两类 benchmark 上没有可比的分数，而同一张表里的其他模型有。
- **决定之前：** 2–2.5 倍的价差值得做 A/B，缺一项跑分值得继续测。两个都做，比只看其中一个结论更靠谱。
