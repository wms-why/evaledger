## 一句话结论

- **$1 / $2.70（每 1M token 输入 / 输出），缓存命中 $0.10。** 输出价比 Claude Opus 5.5 便宜一大截，而 Opus 的输出价是它的数倍——这就是阶跃想卖的「同样智力、更便宜的任务成本」。竞品里最便宜、最像旗舰的那几行，是它真正的参考系。
- **分数落在「国产第一梯队」，不在榜首。** 在厂商自己那张表里，它和 Kimi K3、GLM 5.3 互有胜负；在 Agent 编程与终端任务上落后 GPT-6 Astra 和 Claude Opus。买它是为了价格和吞吐，不是为了拿最高的那根柱子。
- **叫 Preview，叫得没错。** 模型 id 就是 `step-5-preview`，权重在 2026-10-15 才放出，技术报告至今没有。价格、行为、可用性都可以改——把它钉进代码之前，先接受这一点。

## 发布了什么

- **一个旗舰 SKU，id 为 `step-5-preview`。** 2026-09-20 上线，走 OpenAI 兼容的 chat completions 接口；同时可通过 OpenRouter（`stepfun/step-5-preview`）调用，价格与官方的标价一致。
- **600B 总参数、27B 激活的稀疏 MoE。** 1M token 输入窗口、64k 输出上限，支持文本、图片和视频输入，三档思考强度（low / medium / high）。
- **长程任务是这次的宣传重点。** 官方举了三个带时钟的实验：在 H100 上优化 MLA kernel、自动后训练一个小模型、纯凭游戏能力打完一段 Pokemon。这类任务要的不是单题正确率，而是「跑一天不崩」。
- **权重已经放出，但带条件。** BF16、FP8（需审批）、NVFP4 三个 checkpoint 在 Hugging Face 上，许可证是阶跃自己的 Model License 1.0——免费使用与再分发，但月活或营收超过阈值、或以 MaaS 形式转售时，需要单独的商用授权。

## 成本

- **计费单位只有一个：按 token。** 输入分缓存未命中与命中两档，输出包含思考链，没有单独的长上下文加价档。对大多数提示词固定的 Agent 负载来说，缓存命中价才是主力单价。
- **注意缓存写在哪里收费。** 官方把「写入缓存」算进缓存未命中的输入价里，没有 Anthropic 那样单独的缓存写入档。所以一张价格表只要看三个数就够，不必再去拆第四项。
- **对比要拿同一档价格比。** 页面上那张价格表把你关心的模型放在一起，带上各自的上下文窗口和核验日期——一个 400K 窗口的旗舰和一个 1M 窗口的旗舰，每 1M token 的价格不是同一种东西。
- **输出价是成本的大头。** 代码、长文档、Agent 轨迹都是输出密集的负载；如果一次任务里输出占大多数，省钱的杠杆就在输出价和思考长度上，而不在输入。

## 跑分

- **只有厂商自己的一张表。** Step 5 Preview 的分数全部来自阶跃的发布页，没有第三方榜单接手复现；表里其它模型那一列，是阶跃对别家模型的测量，不是我们的测量。
- **档位不对等。** 它跑 High，对手跑 Max。这个差别足以让几列看起来比实际更接近或更远，读到差 1–2 分的行时尤其要克制。
- **表里只留了能对上号的几项。** SWE-Marathon、StepCodeBench、GDPval-AA、GDP.pdf、FinStepBench 这些行，本站在基准注册表里没有对应的 id，所以它们不在表内——不是漏了，是不打算把两个不同仪器测下来的数字放在同一列。
- **这一行还没进榜单排名。** 本站的榜单要求一个模型把一条赛道的核心基准全部测完才有综合分；Step 5 Preview 目前只在部分核心项上有分数，所以它出现在「未排位」里，每一项都标着缺的是哪一项。

## 该不该换

- **输出密集、长时运行的 Agent，值得先试。** 一天跑几百次任务的场景里，输单价与缓存命中价的差距会被放大成账单上的数字，这是它最站得住脚的地方。
- **认准榜单第一的地方，别换。** 最难的那几列（终端任务、仓库级修复）它还不是头部，任务难度就到边界时，省下的钱可能被多跑的轮次吃回去。
- **要稳定 id 的团队，先别换。** Preview 意味着模型名背后可以换权重、价格可以调整。要版本可控，就得同时接受一条纪律：钉住 id、定期回来核对这张价格表的核验日期。
- **要自托管的团队，现在可以算了。** 权重已经开源，最低部署门槛在厂商模型卡里有写——但这是一笔固定成本，按 1M token 的价格算不划算，按「峰值流量不打满」算才算得过来。

## 延伸阅读

- 在计算器里按你自己的用量算一遍：把输入、输出和缓存命中比例填进去，看它和 Opus 5.5、GPT-6 Astra 的月度差额是多少。
- 两两对比：站内的对比页可以把 Step 5 Preview 和任一模型放在一起，价格与分数取自同一份注册表。
- 同一周发布的其它旗舰（Gemini 4 Argon、Claude Opus 5.5）也各有解析，价格结构不一样，值得一起读。
