## 一句话结论

- **DeepSeek V4.1-Flash 0910 高峰价是每 1M token 输入 $0.30、输出 $1.20，非高峰 $0.15 / $0.60——正好一半。** 发布于 2026-09-10。
- **缓存读高峰 $0.006、非高峰 $0.003，是高峰输入价的 2%。** 反复重读的同一段长上下文，重读一次几乎不花钱。
- **注册表里最便宜的模型之一，同时是我们覆盖面最广的一份跑分卡——19 项。** 但这 19 项全部来自同一个出处：发布公告里的对照表，由我们转录。API 后来换到了 1017 checkpoint，价格不变；那个 checkpoint 我们单独记录，单独的表、单独的文章。

## 发布了什么

- **一个带「双档时钟」的 Flash SKU。** 高峰 $0.30 输入 / $1.20 输出（每 1M），非高峰 $0.15 / $0.60，缓存读高峰 $0.006、非高峰 $0.003。
- **官方公布的时间表，原样照抄。** 周一至周五（不含中国法定节假日），高峰为 UTC 01:00–04:00 与 06:00–10:00，其余时间都是非高峰；周末和中国法定节假日全天非高峰。换成北京时间，高峰是 09:00–12:00 和 14:00–18:00。
- **上下文 1,000,000 token**，我们手上的资料里没有长上下文加价档。
- **2026-09-10 发布**，来源是发布公告。本文覆盖的正是那个 checkpoint——0910 那个——因为下面这张表测的就是它。
- **同门还有一个贵几倍的。** DeepSeek V4-Pro 高峰 $1.32 / $3.96，非高峰 $0.66 / $1.98。两个都是 active。

## 成本

- **几点钟调用，价钱差一倍。** 高峰 $0.30 / $1.20，非高峰 $0.15 / $0.60。官方的高峰窗口是工作日的 7 小时（UTC 01:00–04:00 与 06:00–10:00），一周 168 小时里大概占五分之一，其余时间一律半价。
- **对国内团队来说，时区本身就是一张折扣券。** 北京时间 09:00–12:00 和 14:00–18:00 是高峰，其余都是非高峰。夜间跑的批处理、凌晨的定时任务，天然就在便宜的那一档；周末和法定节假日更是全天半价。
- **缓存读 $0.006 是高峰输入价的 2%，省 98%。** 一个每轮都要重读同一份上下文的 Agent 循环，这一行基本决定了账单。
- **和同门 V4-Pro 的差距是 3–4 倍。** Pro 高峰 $1.32 / $3.96：输入是 4.4 倍，输出 3.3 倍；非高峰两者同时减半（Pro 是 $0.66 / $1.98），所以在哪个时段比，比值都一样。
- **上下文 1,000,000 token，没有额外档位。** 按我们手上的资料，提示词再长也是同一个价。

## 跑分

- **这张表说的是 0910 这个 checkpoint，不是 API 今天在服务的那份权重。** API 在 2026-10-17 换到了 1017 checkpoint，价格不变，而那个 checkpoint 公布的是另一组分数——我们单独记录：[/releases/deepseek-v4-1-flash-1017](/zh/releases/deepseek-v4-1-flash-1017)。两个 checkpoint、两张表，绝不合并：发布公告那张表测的是发布时的权重，把它当成今天这批权重来读，正是跑分表最常见的误用。
- **19 项，是我们榜上覆盖面最广的一个模型。** 但它们都来自同一个地方：DeepSeek V4.1 Flash 发布公告里的对照表，我们在 2026-10-19 转录。这让数字彼此自洽、来源可追，同时也意味着它是厂商口径，不是第三方复测。限定条件我们和数字一起印。
- **限定条件必须跟着数字走。** HLE 记的是 36.8，来源注明「纯文本子集上是 39.1」——只报文本子集的模型，和它并不站在同一条起跑线上。Codeforces 是 rating，不是百分比，别和其他列一起平均。
- **看分布，不要看平均分。** 19 项分成两类：知识与数学类偏高（GPQA Diamond 90.9、Codeforces rating 3471、MathArena Apex 65.6），agentic 与编程类的跨度大得多（terminal-bench 2.1 是 90.6，terminal-bench 4.0 只有 31.2）。同一类任务从 2.1 到 4.0 难度递增，分数跟着掉——这是成绩卡的形状，不是某一列塌了。
- **对比行里能看到什么。** 对 GPT-5.6 sol、Claude Opus 5、Gemini 3.1 Pro 这几行旗舰，V4.1-Flash 在 terminal-bench 2.1 上领先，但 3.0 和 4.0 是中游，不是第一。对 Kimi K3、GLM 5.3 这两行，它在 terminal-bench 2.1 和 3.0 上领先，4.0 上则是 GLM 5.3 更高。空格一律读作「没报」，不是零分。
- **覆盖面提醒：** 官方那张表没有覆盖我们追踪的全部 benchmark，所以空格是缺数据，不是差成绩。

## 该不该换

- **你现在用的是旗舰：** 价差 10–20 倍，问题不是「它是不是一样好」，而是「这点质量差距在你的流量上值不值」。分层通常比全量切换更划算：出错的代价高的那部分流量留给旗舰，量大且容错的部分搬到 V4.1-Flash。
- **能错峰的活，就错峰跑。** 夜间批量、每日摘要、离线评测、数据回填——只要避开那两个高峰窗口（北京时间工作日的 09:00–12:00、14:00–18:00），就是半价。这是本篇最便宜的一条优化，改的只是一个定时任务的启动时间。
- **重复读同一段上下文的负载：** $0.006 / 1M 的缓存读会改变你的架构选择——长而稳定的上下文从「负担」变成「可行」。
- **需要 V4-Pro 那档质量：** 注意 Pro 是输入 4.4 倍、输出 3.3 倍，价差只是这件事里小的一半，另一半是那份对照表里的分数——而它只有厂商一个出处。
- **如果是新项目要接入：** 现在 API 服务的是 1017 checkpoint，不是这一个。价格一样、分数更好——在写死任何版本号之前，先读那篇文章。
- **什么会改变我们的建议：** 19 项的第三方复测。现在这些数字是同一份公告里的一张表，我们只是转录了它。这是正当的出处，但它不等于第三方测量。
